Image Workshop
How to use Image Workshop
Working the canvas

Choose Instagram, Feed, or Square to set the correct canvas size.

Click a background to place it on the canvas. Click again to replace it.

Edit text directly on the canvas. Use Add Text in the toolbar to create your own.

Ask Social Vert (right panel) for hook and quote ideas. Tap a chip to load it onto the canvas. Tap a Prompt chip to pre-fill the GenGem prompt box.

Select an object to move, resize, or delete it.

Center moves the selected object to the horizontal center. Delete removes it.

Deleting items from the library removes them permanently.

Generating Backgrounds

Type what you want — a mood, a scene, a color direction.

The image on your canvas is what Gemini sees. Load a version you like and refine it. Clear the canvas to start fresh.

Generated images save to your library automatically. Delete ones you don't want directly from the Generate panel.
